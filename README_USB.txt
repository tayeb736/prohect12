               🏥 MEDISHOP PRO - دليل التشغيل من الـ USB
====================================================================

أهلاً بك! إذا كنت تقرأ هذا الملف، فأنت الآن تحاول تشغيل مشروع 
MediShop Pro على حاسوب جديد.

لديك طريقتان لتشغيل المشروع بناءً على البرامج المثبتة في هذا الحاسوب:

--------------------------------------------------------------------
🟢 الطريقة الأولى: باستخدام Docker (الأسهل والأسرع)
--------------------------------------------------------------------
استخدم هذه الطريقة إذا كان الحاسوب يحتوي على برنامج Docker Desktop.

1. تأكد من تشغيل برنامج Docker Desktop.
2. انقر نقراً مزدوجاً على الملف `START.bat` الموجود بجانب هذا الملف.
3. انتظر قليلاً... سيقوم السكريبت بتشغيل كل شيء (الخلفية، الواجهة، وقاعدة البيانات).
4. سيفتح المتصفح تلقائياً على الرابط: http://localhost:5173

ملاحظة للماك/لينكس: افتح موجه الأوامر (Terminal) واكتب:
sh start.sh

--------------------------------------------------------------------
🔵 الطريقة الثانية: باستخدام Node.js التقليدية
--------------------------------------------------------------------
استخدم هذه الطريقة إذا لم يكن Docker متوفراً، ولكن الحاسوب يحتوي على Node.js.
(إذا لم يكن Node.js مثبتاً، قم بتثبيته أولاً من ملف التثبيت الذي جلبته معك).

الخطوة 1: تشغيل الخادم (Backend)
---------------------------------
1. افتح موجه الأوامر (CMD) داخل مجلد `backend`.
2. اكتب الأوامر التالية بالترتيب:
   npm install
   npx prisma generate
   npx ts-node prisma/seed.ts    <-- هذا لإنشاء الحسابات والبيانات التجريبية
   npm run start:dev

الخطوة 2: تشغيل الواجهة (Frontend)
---------------------------------
1. افتح موجه أوامر (CMD) جديد داخل مجلد `frontend`.
2. اكتب الأوامر التالية:
   npm install
   npm run dev

3. افتح المتصفح على الرابط: http://localhost:5173
